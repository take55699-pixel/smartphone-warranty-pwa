# スマホ補償比較 PWA

主要キャリア・MVNOのスマホ修理・端末補償サービスを比較するPWAです。

## Demo

https://take55699-pixel.github.io/smartphone-warranty-pwa/

## 概要

- スマホ修理・端末補償サービスを一覧で比較
- ブラウザから利用可能
- PWAとしてホーム画面へ追加可能
- スマートフォン向けUI

## PWA

このリポジトリにはWeb App ManifestとService Workerが含まれており、対応ブラウザではWebアプリとしてインストールできます。

## 注意

補償内容・料金・条件は変更される可能性があります。契約や申込みの前に、必ず各事業者の公式情報を確認してください。
